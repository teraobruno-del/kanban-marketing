# Kanban de Gestão de Marketing

Aplicação web estilo Kanban para o setor de Marketing: fluxo de trabalho da equipe,
organização automática por prazo e dashboard para a liderança.

- Especificação: [`docs/SPEC.md`](docs/SPEC.md)
- Decisões aprovadas: [`docs/DECISOES.md`](docs/DECISOES.md)
- Regras e comandos para desenvolvimento: [`CLAUDE.md`](CLAUDE.md)

## Começando

```bash
npm install
npm test
npm run dev
```

Depois abra http://localhost:3000.
